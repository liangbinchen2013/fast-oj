IP 封禁与流量

{{if not .Data.Enabled}}

这一页现在是收起的。这台服务器到目前为止只收到过来自 127.0.0.1 的请求， 说明它前面有一层反向代理（或者只有本机能访问）。这种情况下"按 IP 封禁"两个方向都不可信： 所有访客在服务器眼里都是同一个地址，封谁都等于封全站，而流量表里也只会有一个地址。 要么让代理把真实来源透传到能用的地方（并把服务端的监听地址改成只信任内网转发）， 要么直接让访客连到这台机器的端口上——只要 24 小时内出现过一次非环回来源，这一页就自动打开。

{{end}}

封禁是整站拦死：这个地址之后的任何请求都直接 403，包括题目页、静态资源、 登录与注册，也包括判机回调——所以封之前先看一眼下面的流量表，确认你没把判题机或学校出口 写进去。命中的规则不会显示给来访者，只记在日志里。

写法接受单个地址（203.0.113.9）或 CIDR 网段 （203.0.113.0/24，机房一个出口后面几十台机器时用得上）。 环回地址（127.0.0.1 / ::1）与 0.0.0.0/0、::/0 不让封： 前者在"同机反向代理"的部署里就是所有人，后者封的是全世界，包括按这个按钮的你——而封掉之后 连这一页都打不开，谁也没法再解封。真要停站，用站点开关。 流量计数活在内存里，意思是"本次运行以来"，进程重启归零。
