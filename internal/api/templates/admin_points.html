积分与颜色

积分是活跃度的读数，四个维度各自算分再相加：做题、提交、比赛、社区发言。 名字的颜色就是它的显示：蓝 → 绿 → 橙 → 红。紫=管理员、棕=处罚，只有管理员能设，自动那一路不会改它们； 其余四档由下面这套参数按间隔自动更新。
