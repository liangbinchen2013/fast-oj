功能开关

关掉的意思是"不再收新的"：已发出去的内容、历史成绩、读这些页面都照旧。 考试周想安静点，就把动态、帖子、私信关掉，只留题目和比赛。

下面这一项跟上面五个相反：它是"多一道门"，所以默认关着。 勾上之后新注册的人要先进邮箱点一次链接，才能提交代码和参加比赛； 勾之前就已经存在的账号一律算验证过了，不会被这道门拦住。

提交速率限制

两道闸都是按"一分钟"这个窗口算的，判机是共享资源：队列越长，所有人的结果都越晚出来。 填 0 或留空的意思是"这一条我没设"——按人那条会回到启动参数 -submit-per-minute（这台服务器现在是 {{.Data.Status.StartupSubmit}} 次/分）， 按站那条就是不限量。计数按账号而不是按 IP：一个机房 NAT 出一个地址是常态。

按全站那条挡人时，被挡住的那个人不会被记进他自己那一格——他没有真的提交， 记上就是让他在替站点的忙碌受罚。建题的速率（-problem-per-minute）仍然只在启动参数里。
