接管后台

这是给全新安装用的第一步：把运维令牌填进来，给账号 {{.Data.Handle}} 设一个网页登录密码。设完直接登进来，之后招人照常用 权限控制台。

令牌用一次就作废：对答案之后服务端会当场另生成一枚，新值只打印在服务器日志的 one-time token rotated 那一行里。这样一串被泄露的令牌最多只值一次动作，而不会让人 无限次地把这个站的密码改掉。
